# Week 4 Evaluation Visualisation Review

**Owner:** Aahmad Sayeed  
**Role:** Metrics and Visualisation Lead

## Figures Reviewed

For each classical model:

- confusion matrix;
- one-vs-rest ROC curves;
- one-vs-rest precision–recall curves;
- reliability diagram.

Cross-model figures:

- macro-F1 comparison;
- accuracy comparison;
- attack FPR/FNR comparison;
- training-time comparison;
- inference-time comparison;
- model-size comparison;
- performance–latency trade-off;
- per-class F1 comparison;
- Random Forest feature importance.

## Required Image Quality

- figures saved as PNG;
- 200 DPI;
- readable labels;
- five class names shown consistently;
- no screenshots used as the primary evidence;
- figures generated directly from notebook metrics.

## Interpretation Rule

ROC and PR curves supplement—not replace—per-class F1 and safety-critical error analysis.

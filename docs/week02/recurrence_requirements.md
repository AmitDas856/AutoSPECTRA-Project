# Recurrence-Image Requirements for Later Work

**Owner:** Aahmad Sayeed

## Requirements Identified in Week 2

The future recurrence-image encoder should:

- receive chronologically ordered fixed-length CAN windows;
- use only features created after the Week 3 split;
- avoid target labels and attack ratios;
- create a consistent square image;
- document the signal used to construct pairwise distances;
- compare recurrence images with a simpler matrix baseline;
- report computational cost and information loss;
- visualise at least one unseen example from every class.

## Week Boundary

The recurrence-image encoder and CNN are scheduled for Week 5. Week 2 records only the requirements derived from EDA.

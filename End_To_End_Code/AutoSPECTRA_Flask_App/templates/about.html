Project overview

Deep-learning intrusion detection for the connected car

AutoSPECTRA analyses chronological windows of Controller Area Network traffic and classifies them as Normal, DoS, Fuzzy, Gear spoofing, or RPM spoofing.

Pipeline

  1. Parse timestamp, arbitration ID, DLC, and up to eight payload bytes.
  2. Create fixed chronological windows using the same preprocessing as training.
  3. Run a feature model, recurrence-image CNN, LSTM, or calibrated fusion when the artifacts are available.
  4. Display probability, confidence, timelines, and a deterministic incident report.

Responsible use

This is an academic decision-support prototype trained on a public single-vehicle dataset. High test performance does not establish safe operation across different makes, models, ECUs, environments, or previously unseen attacks. Human review is mandatory.
